1763

奧斯文（第三代）

　　里斯本的工作結束要交接出去回本國時奧斯文殺了埃內亞、將其帶回英國，本打算就直接做成標本之類的東西，沒想到埃內亞復活了。意外之餘奧斯文挺高興，將埃內亞養在避暑地的別墅，一樣安排了閣樓的住處，有去別墅時就會逗埃內亞玩。
　　最嚴重的「遊戲」是將埃內亞帶到地下鬥場，看埃內亞被兇殘的犯人折騰後再反殺，但次數不多，多了怕引起不必要的關注。就算沒有特別的遊戲，單看埃內亞不曾改變的外貌跟死而復生就能逗樂奧斯文。
　　聽家族指示娶了落魄貴族小姐後依然養著埃內亞，但隨著孩子出生減少了去別墅的次數。奧斯文的妻子以為奧斯文在別墅藏了情婦，但因自己才是合法「正宮」且家族仰賴奧斯文的經濟支援，始終當作不知情。
　　奧斯文並未親自照顧埃內亞，而是雇了佣人照料，每五年便整批更換別墅的人，只有少數奧斯文確認不會透露秘密、自己能控制且不會跟埃內亞過份親近的人會常駐。
　　奧斯文有意控制埃內亞跟周圍人的關係：埃內亞長得好看，經歷更給了埃內亞獨特的氣質，常伴身邊的人可能會被埃內亞迷惑、吸引而想要幫助埃內亞。
　　「你應當明白你無法獲得救贖，以及你歸我所有，我當然會捍衛我的所有權。」
　　埃內亞雖有良好的教育跟殺人的知識，但缺乏自保跟獨立生活的能力，因此繼續被圈養，在漫長的時間內學習、練習所有自己能接觸的知識。期間比較親近的對象是奧斯文請來教繪畫與文學的老師布雷克，在雇傭結束後還有保持通信數年的時間，直到奧斯文禁止。
　　（布雷克以埃內亞的形象、半真半假的身世加上自己的想像寫了小說，內容是染了怪病的貴族私生子在尋找治療方法時發現了潛伏黑暗中的怪物……由此展開的故事，書中插畫也是布雷克自己畫的。）
　　奧斯文並未想過要如何安排埃內亞，原本打算就讓埃內亞作為自己財產的一部分留給長子，但偶然在家族聚會中遇到好奇奧斯文的遊歷見聞且對那些有關生死的故事特別感興趣的晚輩。
　　奧斯文想起年輕時的自己，便邀對方去別墅玩，介紹自己最得意的收藏給對方。
　　畢竟這不是誰都能繼承的東西。

英國實業家跟避暑地

「新富商人階層」從 1688 年光榮革命後崛起，至 18 世紀中葉達到高峰。
這時商業資本與殖民貿易壟斷了大量財富。
紡織、貿易、運輸、奴隸、礦業等行業的新富豪藉由買地、進入政界或與貴族通婚獲得頭銜。

18世紀初期，英國的富裕商人和貴族們流行在城市外圍或溫泉小鎮修建「country house」或「summer villa」。
巴斯（Bath）是著名溫泉城市兼渡假首選，周圍丘陵遍佈莊園、別墅，文化氣息濃厚。

奧斯文．恩內斯特（Ernest）

姓氏取自現實中帶領戴比爾斯集團（鑽石壟斷企業）走向輝煌的管理人恩內斯特．歐本海默。

1690 恩內斯特家族開始金三角貿易事業。
1700–30 奧斯文出生、成年、遊歷歐洲，在史特拉斯堡觀刑認識普利莫，後接手埃內亞帶回里斯本。
1730-60 奧斯文回英國結婚生子並將埃內亞安置在巴斯的別墅，埃內亞在別墅接受教育並認識布雷克。
